What should this import do?
  1. To add parts, download the blank template and fill in one part per row.
  2. To update parts, export the current ones, edit the rows in Excel, and upload the same file back — the SKU column tells the import which part each row belongs to.
  3. SKU is the key. Leave it blank to create a new part; keep the exported SKU to update that part (create-and-update mode only). On an update, a blank cell keeps the current value — it never clears data.
  4. Category supports hierarchy using > (e.g., Brake System > Front Brakes). Missing categories are created automatically.
  5. Brand and Unit are created automatically if they don't already exist — the review step lists any new ones so you can catch typos.
  6. To import variants, fill in the Variant columns (Variant Name, Variant Code, etc.) on each row. Rows describing the same part become one product with multiple variants, matched by Variant Code.
  7. Part Number is optional — leave it blank for brands that don't publish a catalog code. Rows with the same Name and a blank Part Number are grouped as one product.
  8. Local Name is optional — the local-language name (e.g. Bengali) staff see alongside the English name.
  9. Upload the completed file, review the validation report, then confirm the import.
